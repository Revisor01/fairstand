# Sicherheit

**Deutsch** · [English](#security)

## Eine Lücke melden

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern
vertraulich auf einem dieser Wege:

- über [„Report a vulnerability“](../../security/advisories/new) in diesem
  Repository (GitHub Private Vulnerability Reporting), oder
- per E-Mail an mail@simonluthe.de mit dem Betreff „Sicherheit: Fairstand“.

Hilfreich sind: betroffene Version, Schritte zum Nachvollziehen, mögliche
Auswirkung. Du bekommst innerhalb von sieben Tagen eine Antwort.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für den jeweils aktuellen Stand von `main`; die
ausgelieferte Web-App folgt ihm automatisch.

# Security

## Reporting a vulnerability

Please do **not** report security issues as a public issue. Report them
privately instead:

- via [“Report a vulnerability”](../../security/advisories/new) in this
  repository (GitHub Private Vulnerability Reporting), or
- by email to mail@simonluthe.de with the subject “Security: Fairstand”.

Helpful: affected version, steps to reproduce, possible impact. You will get a
reply within seven days. Reports in English or German are welcome.

## Supported versions

Security fixes are provided for the current state of `main`; the deployed
web app follows it automatically.
